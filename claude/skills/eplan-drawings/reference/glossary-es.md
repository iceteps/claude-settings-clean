# Machine-translated Spanish in EPLAN drawings

Spanish suppliers often run EPLAN's automatic translation. These are the renderings met in
practice, with what they mean.

| Drawing says | Spanish source | Means |
|---|---|---|
| laundry, washing team, LOVED, WOUND | lavado, lavadero, equipo de lavado | wash, wash unit ("... POST LOVED" = post, washing) |
| table, blackboard | cuadro | panel (general table = main panel) |
| team | equipo | equipment, unit |
| Dcho, Izdo | derecho, izquierdo | right, left |
| disjunct | disyuntor | circuit breaker |
| decalcified, descalcified, discalcified | descalcificada | softened water |
| deposit | depósito | tank |
| BALIZA, foreign balizas | baliza, balizas exteriores | beacon, exterior beacons |
| REMEMA, Remarme | rearme | reset |
| march | marcha | start, run |
| Stuffed box (as in "Stop Stuffed box Start-up") | not certain; probably paro (stop) on the start-up panel | stop button on the panel (inferred from the wiring, not from the words) |
| EV | electroválvula | solenoid valve |
| TRIANGULO | triángulo | delta connection |
| ESTRELLA | estrella | star connection |
| PRENSAESTOPA | prensaestopas | cable gland |
